# MediaHub-BlueGuard

Asistente de ciberseguridad defensiva (**Blue Team**) para el usuario común, integrado en la suite **Media Hub**.

## Características principales
- **Monitor de Red y Puertos en Tiempo Real:** Traduce puertos en escucha (`LISTEN`) y conexiones activas (`ESTABLISHED`) en explicaciones claras y comprensibles.
- **Auditoría de Seguridad Basada en Estándares:** Evaluación práctica alineada con **ISO/IEC 27001 & 27002**, **NIST CSF 2.0**, **CIS Controls v8** y **OWASP**.
- **Traductor de Logs de Windows:** Interpreta eventos del Visor de Eventos de Windows en lenguaje cotidiano.
- **Mitigación Asistida con Consentimiento Explícito (Human-in-the-Loop):** Antes de bloquear un puerto o cerrar una conexión sospechosa, explica qué hará la herramienta, muestra el script auditable exacto y ofrece los botones **Aceptar** y **Denegar**, protegiendo siempre los procesos críticos del sistema operativo.
